// 02. WHAT THIS PLATFORM CAN DO (CAPABILITIES) SELECT ANY MODULE TO LAUNCH
01 // FSE PORTAL (LOGIN WITH SITE DETAILS) PORTAL >>

Field Support Engineers log in using their assigned Site ID, State, and FSE Credentials to unlock dedicated site controls for Fuel, Battery/Light, and Repairs & PPM.

02 // FLEET & FUEL (INPUT LEVEL & DELIVERY TIME) FUEL >>

Input current diesel fuel levels (L), record exact time & date diesel was received, inspect previous date received, and track run-out predictions.

03 // LIGHT & BATTERY (BUB) TELEMETRY BUB >>

Monitor and log battery life (SOC %, bank voltage, off-grid autonomy hours) and the number of hours of utility light (NEPA/PHCN) on site.

04 // REPAIRS & PPM (CONSTANT-REPAIR ASSETS) PPM >>

Identify machinery that requires constant repair, track repeat-fault frequencies, complete site PPM checklists, and log Root Cause Analysis (RCA) tickets.
